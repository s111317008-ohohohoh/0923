各向度詳細說明

班級經營 PR 92 | Avg 3.50

是指教師透過具體的策略與方法，建構全班友善環境與良好班級氣氛，協助小學學生建立生活習性與遵守生活常規。

同儕互動 PR 73 | Avg 3.25

是指教師在國小校園中，與同事、長官、及行政人員之間的人際互動，或與學校單位間的互動。

教師教學 PR 32 | Avg 3.00

是指教師透過多種方式，傳授小學學生在生活上必要的知識、情意及技能，協助學生學習生活必要知識。

學生輔導 PR 61 | Avg 3.11

教師透過同理、教導直接方式，幫助小學學生在心理、情緒、人際、及生涯等各方面的成長與發展。

親師溝通 PR 56 | Avg 3.33

是指教師為協助小學學生，與家長間進行相互的溝通合作，就雙方在教育理念、教養態度等面向上建立共識。
